## 5. Sistema de Generación de Contenidos

### Workflow Paso a Paso

#### Fase 1: Research (1-2 horas)
1. **Keyword Research**
   - Google Keyword Planner
   - Ahrefs/SEMrush
   - Identificar keywords primaria + 3-5 secundarias
   
2. **Análisis de Competencia**
   - Top 10 resultados en Google
   - Identificar gaps de contenido
   - Anotar mejores prácticas

3. **Outline Creation**
   - Estructura H2/H3 con keywords
   - Bullet points de contenido
   - Aproba outline antes de draft

#### Fase 2: Draft (2-4 horas)
1. **Generación Inicial (IA)**
   - Usar Claude/GPT con prompt específico
   - Generar draft 70% completo
   
2. **Edición Humana (Crítico)**
   - Verificar accuracy
   - Agregar voz de marca Andes
   - Personalizar con experiencia local
   - Agregar CTA natural

3. **Optimización SEO**
   - Meta title (50-60 chars)
   - Meta description (150-160 chars)
   - H1 con keyword principal
   - H2/H3 con keywords secundarias
   - Densidad keyword 1-2%
   - Alt text todas las imágenes

#### Fase 3: Assets (1-2 horas)
1. **Imágenes**
   - 1 cover image (16:9, optimizada \u003c150KB)
   - 2-3 imágenes inline si aplica
   - Screenshots/diagramas si es tutorial
   
2. **Optimización**
   - Formato WebP + fallback JPG
   - Compresión sin pérdida visible
   - Responsive srcset

#### Fase 4: Review (30-60 min)
1. **Checklist de Calidad**
   - [ ] Mínimo 1,200 palabras (pilares 2,000+)
   - [ ] 3+ H2 con keywords
   - [ ] Meta tags optimizados
   - [ ] 2-3 links internos
   - [ ] 1 CTA a WhatsApp/plan gratuito
   - [ ] Imágenes optimizadas con alt text
   - [ ] Gramática y ortografía perfectas
   - [ ] Voz de marca Andes

2. **Preview**
   - Verificar rendering markdown
   - Verificar links funcionan
   - Probar en mobile

#### Fase 5: Publish (15 min)
1. **Deploy**
   - Commit a repo
   - Build y deploy
   
2. **SEO Submit**
   - Submit URL a Google Search Console
   - Sitemap auto-update
   
3. **Promoción**
   - Compartir en redes sociales
   - Newsletter si aplica
   - WhatsApp status

#### Fase 6: Monitor (Ongoing)
1. **Track Performance**
   - Google Analytics pageviews
   - Google Search Console rankings
   - CTA clicks
   
2. **Iterate**
   - Actualizar artículos bajo-performing
   - Expandir artículos con alto engagement
   - Ajustar strategy basado en data
